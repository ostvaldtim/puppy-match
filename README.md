# Puppy Match

A small match-3 browser game built as a fast product experiment.

## What it is

- casual match-3 gameplay with puppies
- runs directly in the browser
- mobile-friendly layout
- compact single-file implementation

## What I worked on

- product idea and interaction flow
- gameplay and UX iteration
- implementation review and debugging
- taking the project from a blank idea to a playable browser build

## Tech

`HTML` · `CSS` · `JavaScript`

## Run locally

1. Clone the repository.
2. Open `index.html` in a browser.
