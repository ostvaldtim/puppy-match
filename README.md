# 🐶 Puppy Match

A small **AI-assisted match-3 browser game** built as an experiment in turning a simple idea into a working product quickly.

The goal of this project was not to demonstrate hand-written code line by line. It was to test an **AI-assisted development workflow**: define the product, iterate on UX and mechanics, review generated implementation, fix issues and ship a playable result.

## What it is

- A casual **match-3 game with puppies**.
- Runs directly in the browser.
- Mobile-friendly layout and PWA-oriented metadata.
- Implemented as a compact single-file web application.

## What I did

- Defined the idea and product direction.
- Used AI to generate and iterate on the implementation.
- Reviewed the generated code and adjusted behaviour and UX instead of treating the model output as a finished result.
- Took the project from a blank idea to a playable browser game.

## Why this project is in my portfolio

Puppy Match is a deliberately small project. It shows that I can use AI not only for isolated code snippets, but for the full path from **idea → implementation → debugging → working MVP**.

## Tech

`HTML` · `CSS` · `JavaScript` · AI-assisted development

## Run locally

No build step is required.

1. Clone the repository.
2. Open `index.html` in a browser.
